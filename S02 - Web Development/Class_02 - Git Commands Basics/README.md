# 📂 treino-git-github

Este repositório foi criado com o objetivo exclusivo de praticar comandos de **Git** e fluxo de trabalho no **GitHub**. O código-fonte contido aqui é apenas ilustrativo, pois o foco principal é o treino de versionamento e gerenciamento de repositórios.

## 🎯 Objetivos do Treino

*   **Comandos Básicos:** Praticar `git init`, `git add`, `git commit` e `git push`.
*   **Resolução de Conflitos:** Simular e resolver conflitos de código de forma controlada.
*   **Histórico e Logs:** Analisar o fluxo de commits utilizando `git log` e `git status`.
