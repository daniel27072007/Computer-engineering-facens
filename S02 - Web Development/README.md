# 🌐 S02 - Web Development

This track marks my entry into client-side interface engineering, focusing on structural semantic definitions, visual style sheets, and modern front-end layouts.

---

## Technical Learnings and Implemented Solutions

### 1. Semantic HTML5 Document Structures
* **SEO-Friendly Layout Architecture:** Programmed standard application structures using native semantic wrappers (`<main>`, `<header>`, `<div>`) to decouple information segments cleanly.
* **Document Element Treatment:** Utilized structural list components (`<ul>`, `<li>`) paired with text formatting indicators (`<s>`) to manage programmatic task states.

### 2. Decoupled Presentation Layers & Spacing Normalization
* **Global Box-Model Overrides:** Implemented a universal CSS border reset (`* { box-sizing: border-box; }`) to strip default browser margins, paddings, and alignment quirks.
* **Flexbox Axis Alignment:** Designed centered viewports using standard CSS flexible box models (`display: flex`), managing parent orientation fields along with cross-axis sizing variables (`min-height: 100vh`).
* **Visual Scope Decoupling:** Enforced strict separation of concerns by maintaining visual attributes inside an isolated style sheet (`stylesheet.css`), entirely independent of the underlying core HTML tree structure.
