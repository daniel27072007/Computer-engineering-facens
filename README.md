# 🎓 Academic Software Engineering Portfolio

This repository contains a comprehensive collection of production-grade algorithmic scripts, structural memory architectures, data processing routines, and responsive web layouts developed throughout my computer science graduation graduation tracks at FACENS.

The primary objective of this space is to document my evolution across distinct programming paradigms—ranging from bare-metal procedural execution and low-level system constraints in C/C++ to component-driven front-end engineering.

---

## Technical Core Competencies

The development of these academic modules provided deep practical knowledge across foundational software pillars:

### 1. Low-Level Control Flow & Memory Pipelines
* **Procedural Logic Foundations:** Implementation of deterministic branches, optimized switch structures, and conditional computational pipelines.
* **Hardware-Level Memory Management:** Experience with manual stack/heap manipulation, pointer arithmetic, and reference-passing protocols.

### 2. Multi-Dimensional Data & Transactional Layouts
* **Mathematical Grid Processing:** Engineering matrix scanners capable of localized indexing and complex metric calculations.
* **Stateful CLI Applications:** Development of database-less inventory management consoles utilizing synchronized parallel memory streams.

### 3. Decoupled Web Architectures
* **Semantic Document Modeling:** Building structural layouts designed for accessibility and clean SEO crawling benchmarks.
* **Layout Normalization:** Implementing global CSS resets and advanced flexbox alignment models to eliminate browser rendering discrepancies.
