# 💻 S01 - Algorithms & Programming

This directory documents a structured 12-class computational roadmap designed to build analytical thinking, mathematical abstractions, and standard data structures using native C and C++ environments.

---

## Technical Learnings and Implemented Solutions

### 1. Control Flow Engineering & Dynamic Calculators
* **Deterministic Logic Pipelines:** Implemented optimized conditional workflows utilizing logical expressions to resolve algebraic problems, Fahrenheit-to-Celsius conversion tables, and salary sheet estimations.
* **Structural Router Mapping:** Utilized multi-branch `switch-case` blocks to build operational CLI state systems, such as network status routers (HTTP error code matching) and automated point-of-sale (POS) ordering workflows.

### 2. Iterative Loops & Transactional CLI Engines
* **Boundary Tracking Loops:** Developed advanced loops (`for`, `while`, `do-while`) managing dynamic step indexes to filter numbers, compute multi-variable math sheets, and analyze academic grade metrics.
* **State Machine Simulations:** Programmed a secure banking terminal layout (handling deposit/withdrawal vectors and account overflow conditions) and a fully operational political voting engine featuring real-time percentage processing and tie-breaking algorithms.

### 3. Multi-Dimensional Arrays & Matrix Architecture
* **Array Metrics Optimization:** Developed indexing logic to reverse sequences in memory, extract specific positional flags, and isolate data arrays.
* **Advanced Grid Algebra:** Built matrix processors executing scale transformations, identity diagonal extraction, and a custom implementation of the **Minimax Mathematical Algorithm** (detecting the row containing the absolute maximum matrix element, then isolating its minimum variable).

### 4. String Engineering & Local Database Records
* **String Parsing Protocols:** Engineered secure password verification layers using string utilities (`strlen`, `strcmp`, `strcat`) to perform length enforcement, character matching, and capitalization filters.
* **Parallel Memory Systems:** Designed an autonomous local inventory terminal managing parallel memory registers (`estoque`, `nomeProduto`, `infoProduto`). The tool handles product registration constraints, item search indexes, product listing catalogs, and selective item level adjustments.

## Folder Content Manifest

The module is divided into progressive academic units containing the raw source code sheets:
* **`A01_Class` to `A02_Class`:** Core syntax, variable type allocation, and mathematical routines.
* **`A03_Class` to `A05_Class`:** Advanced conditional branches, Boolean expressions, and POS layouts.
* **`A06_Class` to `A07_Class`:** Loop validation structures, transaction handlers, and string engines.
* **`A08_Class` to `A10_Class`:** Single/multi-dimensional arrays, matrix algorithms, and grid algebra.
* **`A11_Class` to `A12_Class`:** String processing pipelines and the parallel-array inventory terminal.
